모니펫 개인정보처리방침

웨얼아유마이홈 · 시행일 2026년 11월 1일 · 최종 수정 2026년 11월 3일 · English · 계정 삭제 방법

웨얼아유마이홈(이하 "회사")은 바탕화면 펫 게임 모니펫(Windows 앱 · Android 앱, 이하 "서비스")을 운영하며, 「개인정보 보호법」 등 관련 법령을 지킵니다. 이 방침은 서비스가 어떤 정보를 왜 처리하는지, 얼마나 보관하는지, 이용자가 어떻게 지울 수 있는지 알려 드립니다.

요약
  • PC 앱은 이름 · 이메일 · 전화번호 없이 익명 계정으로 시작합니다. 폰 앱에서 새로 시작할 때는 펫을 잃어버리지 않게 구글 · 카카오 · 이메일 로그인을 씁니다.
  • 로그인 정보는 펫을 지키고, 다른 기기로 옮기거나 되찾을 때만 씁니다.
  • 만 14세 이상만 이용할 수 있습니다. 만 14세 미만 아동의 개인정보는 수집하지 않습니다 (6절).
  • Android 앱에는 Google AdMob 보상형 광고가 있습니다. 이용자가 "광고 보고 받기" 를 직접 누를 때만 나오며, 배너 · 전면 광고는 없습니다. 광고를 보여 주는 동안 Google 이 광고 ID 등을 처리합니다 (3절 광고). Windows 앱에는 광고가 없습니다.
  • 그 밖의 분석 · 추적 · 오류 수집 도구는 쓰지 않으며, 위치 · 연락처 · 사진 · 파일 · 마이크 · 카메라에 접근하지 않습니다.
  • 정보를 팔지 않습니다.
  • 지금은 유료 결제(유료 상품)를 제공하지 않습니다.
  • 앱 안에서 언제든 계정과 모든 게임 데이터를 지울 수 있습니다.

2. 보관 기간

  • 계정과 게임 데이터는 계정을 삭제할 때까지 보관하고, 삭제하면 바로 지웁니다.
  • 로그인 수단(구글 · 카카오 · 이메일)을 연결하지 않았고 펫도 없는 익명 계정은 30일 동안 쓰지 않으면 자동으로 삭제합니다.
  • 연결 코드는 10분이 지나면 쓸 수 없고, 연결 시도 횟수는 10분 단위로 다시 셉니다.
  • 나이 확인 기록은 계정을 삭제할 때까지 보관합니다.
  • 광고 보상 기록은 계정을 삭제할 때까지 보관하고, 광고 확인 진단 기록(계정 정보 없음)은 7일 뒤 지웁니다. Google 이 광고를 보여 주며 처리하는 정보는 Google 의 정책에 따라 보관됩니다.
  • 서버 접속 기록은 서비스 제공 업체(Supabase)의 정책에 따라 짧은 기간 보관 후 지워집니다.
  • 법령이 따로 보관을 요구하면 그 기간 동안만 보관합니다.

광고 (Android 앱의 보상형 광고)

  • Android 앱은 Google AdMob 보상형 광고를 씁니다. 광고는 이용자가 "광고 보고 받기" 단추를 직접 누를 때만 나오고, 끝까지 보면 게임 안 보상(알 빨리 깨기 · 원정 금화 · 무료 뽑기 등)을 받습니다. 배너 · 전면 · 앱 열기 광고는 없고, 광고를 보지 않아도 게임을 할 수 있습니다. Windows 앱에는 광고가 없습니다.
  • 광고를 불러오고 보여 주는 동안 Google 이 광고 ID(Android 광고 식별자), 기기 · 앱 정보(기기 종류, 운영체제 버전, 앱 버전 등), IP 주소로 짐작한 대략적인 위치, 광고와의 상호작용 정보를 수집 · 처리할 수 있습니다. 목적은 광고 제공, 광고 성과 측정, 부정 이용 방지입니다. Google 이 이 정보를 처리하는 방식은 Google 광고 정책 (policies.google.com/technologies/ads) 을 따릅니다.
  • 필요한 지역에서는 처음 광고를 볼 때 Google 의 동의 창이 뜨며, 동의하지 않으면 맞춤형이 아닌 광고를 보여 줍니다. 광고는 12세 이상 등급(T) 이하의 내용만 나오도록 설정해 두었습니다.
  • 광고를 끝까지 보면 Google 이 회사 서버로 시청 확인(계정 식별자 · 보상 칸 · 1회용 번호 · 광고 거래 번호 포함)을 보내고, 서버가 Google 서명을 확인한 뒤 보상을 줍니다. 회사는 이 확인 정보를 광고 ID 와 연결하지 않습니다.
  • 광고 ID 재설정 · 맞춤 광고 끄기: Android 기기의 설정 → Google → 광고 (기기에 따라 설정 → 개인정보 보호 → 광고) 에서 "광고 ID 재설정" 이나 "광고 ID 삭제" 를 누르면 됩니다. 광고 ID 를 지워도 보상형 광고는 볼 수 있지만, 맞춤형이 아닌 광고가 나옵니다.

4. 계정 · 데이터 삭제 방법

앱에서 직접 (바로 처리)

  • Android 앱: 아래 📖 기록 탭 → 맨 아래 ⚙️ 설정의 👤 계정 관리 → 🗑 계정 삭제 → 안내를 읽고 계속 → 칸에 "삭제" 입력 → 영구 삭제
  • Windows 앱: 작업 표시줄 알림 영역(트레이)의 모니펫 아이콘 → 📖 도감 → 👤 계정 탭 → 🗑 계정 삭제 → 안내를 읽고 계속 → 칸에 "삭제" 입력 → 영구 삭제

삭제하면 그 계정의 펫 저장, 보유 펫 · 게임 재화 · 꾸미기, 광고 보상 기록 등 각종 기록, 친구 · 방문 · 놀이터 기록, 기기 연결 정보, 연결된 로그인 수단(구글 · 카카오 · 이메일) 정보가 서버에서 바로 모두 지워지고 되돌릴 수 없습니다. 폰에서 삭제하면 이 폰 계정과 연결된 PC 의 펫 계정이 함께 지워집니다. PC 에서 삭제하면 연결된 폰의 연결도 끊깁니다. 같은 구글 · 카카오 · 이메일로 다시 로그인해도 지운 펫은 돌아오지 않습니다. 따로 남겨 두는 데이터는 없습니다(서비스 제공 업체의 짧은 보안 기록은 2와 같이 자동으로 지워집니다).

6. 아동 · 청소년

  • 만 14세 미만은 이용할 수 없으며, 만 14세 미만 아동의 개인정보는 수집하지 않습니다. 폰 앱과 PC 앱의 로그인 화면에는 "만 14세 이상이며, 개인정보처리방침에 동의해요" 체크가 있고, 이 체크를 해야 로그인 · 계정 연결을 할 수 있습니다. 태어난 해 · 달 · 날짜는 묻지 않으며, 체크하고 로그인했다는 기록만 계정에 남깁니다.
  • 만 14세 미만 아동이 체크를 하고 이용한 사실을 알게 되면 그 계정의 정보를 지웁니다. 보호자는 4절의 이메일로 삭제를 요청할 수 있습니다.
  • 지금은 유료 결제(유료 상품)를 제공하지 않습니다. 유료 기능이 생기면 이 방침과 앱에서 결제 전에 안내합니다.

7. 안전성 확보 조치

  • 모든 통신은 암호화(HTTPS)합니다.
  • 데이터베이스의 모든 표에 행 단위 접근 제한을 걸어, 이용자는 자기 계정(과 연결된 기기)의 데이터만 읽을 수 있고, 쓰기는 계정별 권한을 확인하는 서버 함수로만 합니다.
